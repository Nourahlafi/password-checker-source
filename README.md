# Password Strength Checker

A simple tool that checks how strong your password is.

## How to use
1. Download `password_checker.exe` from the Releases page
2. Double-click to run it
3. Type the password you want to check
4. Type `exit` or `quit` to close the program

## Privacy
Everything runs locally on your computer. Your password is never sent anywhere.

## Notes
- Works on Windows only
- Your antivirus may show a warning. This is common with PyInstaller executables.
